# Minecraft 皮肤贴图 ↔ 立体部位 对照（速查）

皮肤贴图是一张**展开图（UV 图）**：把方块人剪开摊平。记住两条规则就能定位任何一块像素。

## 规则 1：每个方块都是「十字带」

```
            [ 顶面 ]
[ 右面 ][ 正面 ][ 左面 ][ 背面 ]
            [ 底面 ]
```

一条 4 格宽的横条从左到右读作「右面、正面、左面、背面」；上方接顶面、下方接底面。
这里的「右面」= **角色自己的右手边**（模型里是 -X 侧）。

## 规则 2：各部位方块尺寸不同

| 部位 | 方块尺寸（宽×高×厚） | 贴图上占的块 |
|---|---|---|
| 头 | 8×8×8 | 32×16 一带 |
| 躯干 | 8×12×4 | 40×16 一带 |
| 手臂 | 4×12×4 | 16×16 一带 |
| 腿 | 4×12×4 | 16×16 一带 |

## 4×4 格子速查（16 个 16×16 格子）

| 列 0–16 | 列 16–32 | 列 32–48 | 列 48–64 |
|---|---|---|---|
| 头 | 头（其余面） | 帽子外层（上 8 行） | 帽子外层（其余） |
| 右腿 | 躯干（左 8 列） | 躯干（其余） | 右臂 |
| 右裤外层 | 外套外层 | 右袖外层 | 右臂外层 |
| 左裤外层 | 左腿 | 左臂 | 左袖外层 |

记这张表比记坐标快。**练手记忆**：第 2 行第 4 格永远是右臂，第 4 行第 4 格永远是左袖外层。

## 64×32 旧版格式

- 与 64×64 是**同一像素网格**，只是只填了其中几块：上半 `(0,0)-(64,16)` 是头，
  下半依次是右腿 `(0,16)-(16,32)`、躯干 `(16,16)-(40,32)`、右臂 `(40,16)-(56,32)`。
- 没有左臂/左腿/袖/裤/帽子/外套的独立区域。
- 左肢在旧版里复用右肢贴图，但游戏里左右肢体镜像摆放，所以左臂看起来是右臂的镜像。
- 用 `node bin/skin.mjs convert legacy.png -o modern.png` 升级到 64×64：
  原 4 块 1:1 保留，左臂/左腿按**逐面水平镜像**补齐，外层用基础层内容填充。
